# Moment Energía App

App multiarchivo para GitHub Pages.

## Páginas
- index.html: landing pública
- servicios.html
- packs.html
- calculadora.html
- reserva.html
- faq.html
- panel.html: CRM interno
- presupuestos.html
- plantillas.html
- backup.html

## BBDD interna
Usa IndexedDB en el navegador. No requiere servidor. Exporta JSON desde backup.html de forma periódica.

## Acceso interno
Clave local inicial: `moment2026`. Es una protección local básica para una app estática en GitHub Pages; no sustituye autenticación de servidor.
